# Plus Jakarta Sans

Font utama web SIGAP, disajikan lokal agar tetap tersedia tanpa koneksi ke penyedia font.

- Berkas: `plus-jakarta-sans-latin-variable.woff2`, subset Latin, normal, bobot 200–800.
- Sumber: [Google Fonts](https://fonts.google.com/specimen/Plus+Jakarta+Sans).
- Pembuat: [The Plus Jakarta Sans Project Authors](https://github.com/tokotype/PlusJakartaSans).
- Lisensi: SIL Open Font License 1.1; lihat [berkas lisensi](OFL-Plus-Jakarta-Sans.txt).
- Konfigurasi `@font-face` dan token Tailwind `--font-sans` berada di `web/src/index.css`.

# Instrument Serif

Font judul (serif) di landing page, disajikan lokal.

- Berkas: `instrument-serif-latin-regular.woff2` dan `instrument-serif-latin-italic.woff2`, subset Latin.
- Sumber: [Google Fonts](https://fonts.google.com/specimen/Instrument+Serif).
- Pembuat: [The Instrument Serif Project Authors](https://github.com/Instrument/instrument-serif).
- Lisensi: SIL Open Font License 1.1; lihat [berkas lisensi](OFL-Instrument-Serif.txt).
- Konfigurasi `@font-face` berada di `web/src/pages/LandingPage.css`.
